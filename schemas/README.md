# Schema 使用说明

`draft.schema.json` 是生成输出约定，采用 JSON Schema Draft 2020-12。它是设计交付的一部分，尚未验证所有模型供应商或 n8n 节点都支持其全部关键字。

实施时如模型接口只支持子集，应在适配层提供简化版本；Python 仍按完整 Schema 校验。不要删除服务端验证以迁就模型。

Schema 之外还必须由 Python 验证：

- 三个 variant_id 恰好各出现一次。
- 所有 revision 与预留生成尝试中的上下文一致。
- 每个 fact_id 均存在、已确认并属于当前版本。
- claims 覆盖标题/正文中的事实；存在引用并不证明陈述得到支持。
- 商品参数与销售条件不存在明显冲突。
- 重复表达、未知承诺、图片使用权限和批准版本绑定。

中文字符长度按所用验证器的 Unicode 字符语义实现并测试。真正发布时再适配平台的字段限制；这里的 50/1500 是项目初始上限。
